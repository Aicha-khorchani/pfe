CRM , documents ( reception notes invoice notes delivery notes ) and parterns managment system has dashboards about partners productivity and efficency (suppliers , delivery company , clients , leads...) as well as invoice and stock tracking system with also dashboards about sales and stock & restocks accounts managements 


go to requirment.txt file level and run this to install this project requirments: pip install -r requirements.txt  
go to script file level and run this to activate the virtual envirment: activate
go back to saleManagment level and run: python manage.py makemigration 
then run to create database: python manage.py migrate
and finally run this to open server and consult project: python manage.py runserver
make sure the cmnds with manage.py be run in the same level as the manage.py file in your machine
